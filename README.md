# 摄像头组智能车 · 整车控制软件

基于 **STC32G144K256** 的摄像头循迹方案，独立完成全部控制软件（C，约 3 千行）。
在没有 FPU、没有图像硬件加速的 251 内核 MCU 上，用纯灰度传统视觉实现实时的
「采集 → 阈值 → 边线 → 中线 → 转向 + 速度闭环」全链路。

> 全国大学生智能汽车竞赛（摄像头组）

---

## 硬件平台

| 部件 | 型号 / 说明 |
|---|---|
| 主控 | STC32G144K256 @ 96 MHz（无 FPU、无图像加速） |
| 摄像头 | MT9V03X，188 × 120 灰度 |
| 执行 | 舵机（PWM 50 Hz）+ 双直流电机（PWM 驱动 + 正交编码器测速） |
| 姿态 | IMU660RB，陀螺仪 Z 轴参与转向阻尼 |
| 测距 / 执行器 | DL1B ToF 测距 + 5 路激光 |
| 显示 | IPS200 |
| 调试 | WiFi-SPI 图传 + 逐飞助手上位机（图像 / 边界 / 调试变量实时回传） |

## 软件结构

```
user/
  main.c        主循环：取图 → 自适应阈值 → 基准列 → 搜线 → 中线 → 元素 → 舵机
  isr.c         GPIO 中断分发
src/
  line.c        自适应阈值、基准列定位、边线提取、干扰抑制、加权中线
  yuansu.c      环岛状态机、目标检测、十字判据
  pid.c         位置式 PD（微分项一阶低通）、增量式 PID
  servo.c       舵机输出（视觉 PD + 陀螺仪阻尼）
  motor.c       编码器测速、速度环、差速控制
  jiguang.c     DL1B 测距与激光触发时序
  function.c    插值、限幅等工具函数
```

## 关键实现

### 1. 自适应阈值（替代固定阈值）

取图像底部 5 行的灰度均值作为环境参考点，按 ×1.3 / ×0.7 推导白点上限与黑点下限，
并限幅在 `[50, 255]`。固定阈值在阴影、强光下会整幅二值化失效，这一层是鲁棒性的基础。

### 2. 基准列定位（"最长白列"）

逐列自底向上扫描，记录每列白区的上边界行号，取「白色延伸最长」的一列作为搜线起点。
列方向按步长 3 跳采；每列的搜索起点沿用上一列的边界行，省掉大量重复扫描。

### 3. 连续性跟踪提取边线

逐行自底向上，以上一行边界 ±5 列为起点向外搜索「白 → 黑」灰度跳变，命中即锁存。
本质是把全行扫描收缩成一个十几像素的局部窗口。

### 4. 双层干扰抑制（圆环 / 十字）

- **宽度滤波**：跳变点外侧 6 px 仍为白 → 判为细黑线干扰，跳过继续搜
- **黑点计数**：向上连续黑像素 ≥ 8 才确认为真实边界；< 5 判为圆环内圈
- **失配回退**：单行搜不到时回到基准列整行重扫

### 5. 加权中线 + 限幅 + 一阶滤波

行内左右边界取中点后，按行加权求等效中线（权重峰值落在第 83–86 行，即前瞻行），
叠加 `(last + cur) / 2` 一阶滤波与 ±30 限幅，抑制中线跳变。

### 6. 转向：PD + 陀螺仪阻尼 + 分段变增益

- 位置式 PD，微分项带一阶低通（`Out_D = Δe·α + Out_D·(1-α)`）
- 叠加陀螺仪 Z 轴角速度阻尼（±30 死区，系数 0.005）抑制过冲
- 按横向误差分三段切换 Kp：直道稳、弯道灵

### 7. 速度环：增量式 PID

编码器测速 → 野值剔除（单周期跳变 > 300 判为噪声）→ 一阶低通（0.4 / 0.6）→
增量式 PID → 左右差速。
