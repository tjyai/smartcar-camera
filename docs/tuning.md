# 调参记录

所有参数均取自实际代码（文件 / 变量可对照），不是事后补写的理论值。

---

## 一、图像与阈值（`src/line.h`）

| 参数 | 取值 | 依据 |
|---|---|---|
| `REFRENCEROW` | 5 | 取底部 5 行求均值。行数太少受噪声影响，太多会把远处亮区算进来 |
| `WHITEMAXMUL` | 13（×1.3） | 白点上限。低于这个倍数，浅灰赛道会被判成黑 |
| `WHITEMINMUL` | 7（×0.7） | 黑点下限。配合上限形成滞回带，避免边界反复跳 |
| `BLACKPOINT` | 50 | 阈值下限，防止全黑画面时上限过低 |
| `MID_W` | 94 | 赛道中线基准（图像宽 188） |
| `mid_line_limit` | 30 | 中线限幅，超过视为异常帧 |

**调试过程**：固定阈值在树荫、反光地带整幅崩掉，改成按底部均值浮动后，
同一组参数能同时过室内和室外两种光。

## 二、搜线（`src/line.c`）

| 参数 | 取值 | 依据 |
|---|---|---|
| 列向步长 `CONTRASTOFFSET` | 3 | 188 列全扫太慢，步长 3 时约 63 列，仍能覆盖赛道 |
| 行起点偏移 `ROW_CONTRAST_OFFSET` | 3 | 相邻列边界通常只差几行，从上一列边界 +3 开始扫 |
| 横向搜索半径 `SEARCHRANGE` | ±5 列 | 兼顾连续性约束与急弯；小于 5 会跟不上大弯 |
| 搜索终止行 `search_end_line` | 30 | 顶部 30 行是远景噪声区，不参与 |
| 停止行 `STOPROW` | 3 | 避免数组越界 |

**连续性约束的代价**：急弯时邻列边界跳变可能超过 5 列，此时会漏搜；
靠「单行失配 → 回退基准列整行重扫」兜底。

## 三、干扰抑制（`src/line.c`）

| 参数 | 取值 | 含义 |
|---|---|---|
| 宽度滤波偏移 | 6 px | 跳变点外侧 6 px 仍为白 → 判为细黑线（圆环/十字干扰） |
| `BLACK_RING_MAX` | 8 | 向上连续黑像素 ≥ 8 才确认为真实边界 |
| `CONSECUTIVE_BLACK` | 5 | 连续黑 < 5 判为干扰段，跳过继续搜 |

**为什么是 8**：赛道边线宽度在 188×120 下约 10–15 px，圆环内圈只有 3–5 px。
取 8 作为分界，实测能滤掉大部分圆环误判，又不会误伤正常边线。

## 四、中线（`src/line.c`）

| 参数 | 取值 | 依据 |
|---|---|---|
| 加权表峰值 | 20，位于第 83–86 行 | 权重峰值即「等效前瞻行」，压在这儿最贴合前瞻距离 |
| 一阶滤波 | `(last + cur) >> 1` | 0.5 系数，抑制跳变；代价是约 1 帧延迟 |
| 限幅 | ±30 | 超出直接截断，防止单帧异常把舵机打死 |

**取舍**：滤波越重越稳但越滞后，弯道入口容易切内线；0.5 是实测下来
「直道不抖 + 弯道不迟」的折中点。

## 五、转向（`src/servo.c` + `src/pid.c`）

| 参数 | 取值 | 依据 |
|---|---|---|
| PID 结构 | 位置式 PD（无 I） | 转向是纯比例-微分关系，积分项会累积导致回正慢 |
| 微分低通 | `Out_D = Δe·α + Out_D·(1-α)` | 原始微分对图像噪声极敏感，必须滤 |
| 陀螺仪死区 | ±30 | 静止时陀螺输出有零漂，小于 30 视为 0 |
| 陀螺仪系数 | 0.005 | 只做阻尼不做主导，视觉仍是主反馈 |
| 舵机限幅 | ±`turn_*_duoji_limit` | 机械行程保护 |

**分段变增益**（`dynamic_pid_value_set`）：

| 横向误差 | Kp | 理由 |
|---|---|---|
| < 8 | 0.4 | 直道，降低增益防抖 |
| 8 ~ 20 | 0.6 + (e−8)×0.0025 | 缓弯，随误差线性加大 |
| ≥ 20 | 继续增大 | 急弯，需要快速打到舵量 |

单组 Kp 跑全程的矛盾：大了直道抖，小了弯道切不进去。分段后两者兼顾。

## 六、速度环（`src/motor.c`）

| 参数 | 取值 | 依据 |
|---|---|---|
| 测速野值剔除 | 单周期跳变 > 300 丢弃 | 编码器受干扰时会出现单点巨值 |
| 测速一阶滤波 | `0.4·old + 0.6·new` | 兼顾响应与平滑 |
| 速度环 | 增量式 PID | 输出是 PWM 增量，天然带积分，抗负载扰 |
| PWM 限幅 `pid_limit` | 上限固定 | 防止 PID 输出超过电机安全占空比 |
| 基础速度 | 100 | 直道巡航基准 |
| 差速系数 | 0.4 / 1.0 / 1.2（按误差三段） | 直道几乎不差速，急弯大幅差速帮助转向 |

**加减速斜率**：加速每 20 ms 周期 +20，减速 −30。
加速要柔（防打滑），减速要快（入弯前必须把速度降下来）。

## 七、元素（`src/yuansu.c`）

| 项 | 说明 |
|---|---|
| 环岛状态机 | 7 态：`RING_NONE / IN / ARC / PREPARE / ENTERING / INSIDE / EXITING` |
| 状态迁移依据 | 边线突变、赛道宽度变化、圆弧特征点 |
| 冷却时间 | 50 帧（约 1 秒），防止同一元素重复触发 |
| 十字判据 | 中段赛道宽度积分超阈值 → 判定十字，补线或强制直行 |

代码中保留了 20 余个 `debug_*` 计数器（`debug_arc_fail`、`debug_valley_ok`、
`debug_steady_jump` 等），用于逐项验证状态迁移条件，是这套状态机能调出来的原因。

## 八、激光打靶（`src/jiguang.c`）

| 参数 | 取值 | 说明 |
|---|---|---|
| 定时器 | 5 ms PIT | 驱动激光关断与 DL1B 采样节拍 |
| DL1B 触发 | 每 10 个节拍（50 ms） | 测距模块响应没那么快 |
| 激光保持 | 10 帧 | 触发后保持时长 |
| 选通规则 | 按目标圆心列区间选 5 路激光之一 | 左 1 / 左 2 / 中 / 右 2 / 右 1 |
| 冷却 | 50 帧 | 防止同一目标重复触发 |

## 九、走过的弯路（留存备查）

1. **固定阈值** → 光照一变就废，改自适应
2. **全列全行扫描** → 帧率不够，改列跳采 + 连续性约束 + 局部窗口
3. **纯微分** → 噪声放大，加一阶低通
4. **单组 Kp** → 直道抖弯道软，改分段变增益
5. **十字补线** → 误判率高，最终改为关闭补线、强制直行（保留 `cross_analysis()` 未启用）
